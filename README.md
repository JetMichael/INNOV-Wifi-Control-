## iiLink / iiLink 控制

App Description / 应用描述
INNOV IoT application for managing and monitoring INNOV smart devices over the cloud. View real-time battery / BMS telemetry, receive threshold-based alarms, provision devices via Bluetooth or BluFi, and communicate with devices over WiFi.
通过云端管理与监控 INNOV 智能设备的物联网应用。查看电池 / BMS 实时遥测、接收阈值告警、通过蓝牙或 BluFi 为设备配网，并基于 WiFi 与设备通信。

## Main Features / 主要功能
- Cloud device management: bind, rename, search and monitor INNOV devices / 云端设备管理：绑定、重命名、搜索与监控设备
- Real-time telemetry: SOC, voltage, current, temperature, SOH, cell voltages / 实时遥测：电量、电压、电流、温度、健康度、单体电压
- Threshold alarms & local notifications / 阈值告警与本地通知
- Bluetooth & BluFi provisioning (WiFi network setup) / 蓝牙与 BluFi 配网（WiFi 网络配置）
- WiFi TCP communication / debugging console / WiFi TCP 通信与调试控制台
- QR code scanning to bind devices / 扫码绑定设备
- CAN bus recording via Bluetooth / 通过蓝牙录制 CAN 总线数据
- Multi-user accounts with roles (operator / admin / super admin) / 多用户账户与角色权限
- Chinese and English interface / 中英文界面

## Technical Info / 技术信息
- Framework: Flutter / 开发框架：Flutter
- Bluetooth: FlutterBluePlus / 蓝牙库：FlutterBluePlus
- Backend: REST API (device telemetry & accounts) / 后端：REST 接口（设备遥测与账户）
- Local network: TCP socket communication / 局域网：TCP Socket 通信
- Supported OS: iOS 16.0+ / Android / 支持系统：iOS 16.0+ / Android
